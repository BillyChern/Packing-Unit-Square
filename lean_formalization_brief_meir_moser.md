# Lean Formalization and Certified Proof Brief for the Meir–Moser Rectangle Packing Project

**Purpose:** This file supplements the research note and the coding-agent execution brief.  
**Goal:** The final research output should not only be a paper and Python experiments, but also a Lean 4 formalization that machine-checks the main mathematical claims and verifies finite certificates.

> Important: Do **not** use Lean merely as decoration. The target is a real proof artifact: no `sorry`, no untracked axioms in the final theorem, and CI that runs `lake build`.

---

## 1. Why Lean is required

The Meir–Moser rectangle problem is delicate because small geometric bookkeeping errors can invalidate a near-density-one packing proof. A Lean formalization should serve three roles:

1. **Formal theorem checker** for the lemmas in the paper.
2. **Certificate checker** for finite warm-start states generated by Python/C++ experiments.
3. **Bridge between computation and proof**: if a certificate is accepted by Lean, the paper can cite a machine-checked theorem rather than relying on floating-point pictures.

Lean 4 is an interactive theorem prover; the official Lean documentation describes it as a framework for fully specified axiomatic proofs, and Mathlib is the community mathematical library for Lean 4. See the official Lean 4 theorem proving text and Mathlib repository/documentation for current setup and library conventions:
- Theorem Proving in Lean 4: <https://leanprover.github.io/theorem_proving_in_lean4/>
- Mathlib4 repository: <https://github.com/leanprover-community/mathlib4>
- Lean Mathlib use case page: <https://lean-lang.org/use-cases/mathlib/>

1. **Foundational geometry and finite certificates**

## 5. Layer 1: geometry primitives

### 5.1 Rectangles

Use rational coordinates first.

Suggested Lean structure:

```lean
import Mathlib.Data.Rat.Basic
import Mathlib.Data.Real.Basic

namespace MeirMoser

structure Rect where
  x0 : ℚ
  y0 : ℚ
  x1 : ℚ
  y1 : ℚ
  hx : x0 ≤ x1
  hy : y0 ≤ y1
deriving Repr
```

Define:

```lean
def Rect.width (R : Rect) : ℚ := R.x1 - R.x0
def Rect.height (R : Rect) : ℚ := R.y1 - R.y0
def Rect.area (R : Rect) : ℚ := R.width * R.height
def Rect.semiperim (R : Rect) : ℚ := R.width + R.height
```

Prove basic nonnegativity:

```lean
lemma Rect.width_nonneg (R : Rect) : 0 ≤ R.width := ...
lemma Rect.height_nonneg (R : Rect) : 0 ≤ R.height := ...
lemma Rect.area_nonneg (R : Rect) : 0 ≤ R.area := ...
```

### 5.2 Containment and disjoint interiors

Define closed containment:

```lean
def Rect.contains (A B : Rect) : Prop :=
  A.x0 ≤ B.x0 ∧ B.x1 ≤ A.x1 ∧ A.y0 ≤ B.y0 ∧ B.y1 ≤ A.y1
```

Define interior-disjointness:

```lean
def Rect.interiorDisjoint (A B : Rect) : Prop :=
  A.x1 ≤ B.x0 ∨ B.x1 ≤ A.x0 ∨ A.y1 ≤ B.y0 ∨ B.y1 ≤ A.y0
```

Prove symmetry:

```lean
theorem interiorDisjoint_symm :
  Rect.interiorDisjoint A B → Rect.interiorDisjoint B A := ...
```

### 5.3 Rectangle sequence

Define dimensions of \(D_n\). Avoid \(n=0\).

```lean
def D_width (n : ℕ) : ℚ := 1 / (n : ℚ)
def D_height (n : ℕ) : ℚ := 1 / ((n + 1 : ℕ) : ℚ)
```

For safety, use positive natural indices:

```lean
structure PosNat where
  val : ℕ
  pos : 0 < val
```

or simply state theorems under `0 < n`.

Define:

```lean
def D_area (n : ℕ) : ℚ := 1 / ((n : ℚ) * ((n+1 : ℕ) : ℚ))
```

Prove:

```lean
theorem D_area_eq (hn : 0 < n) :
  D_width n * D_height n = D_area n := ...
```

## 6. Layer 1: finite packing certificates

### 6.1 Placed rectangles

```lean
structure PlacedRect where
  n : ℕ
  hn : 0 < n
  rect : Rect
  rotated : Bool
```

Define dimension correctness:

```lean
def PlacedRect.validDims (P : PlacedRect) : Prop :=
  if P.rotated then
    P.rect.width = D_height P.n ∧ P.rect.height = D_width P.n
  else
    P.rect.width = D_width P.n ∧ P.rect.height = D_height P.n
```

### 6.2 Finite packing predicate

```lean
def FinitePacking
  (container : Rect)
  (placed : List PlacedRect)
  : Prop :=
  (∀ P ∈ placed, container.contains P.rect) ∧
  (∀ P ∈ placed, P.validDims) ∧
  (∀ P Q, P ∈ placed → Q ∈ placed → P ≠ Q →
      Rect.interiorDisjoint P.rect Q.rect)
```

### 6.3 Certificate soundness

The Python code may export a certificate as a Lean file containing explicit rational rectangles.

Lean should prove:

```lean
theorem certificate_sound
  (container : Rect)
  (placed : List PlacedRect)
  (h : FinitePacking container placed) :
  ∃ packing, True := ...
```

More concretely, if a certificate file defines:

```lean
def candidateContainer : Rect := ...
def candidatePlaced : List PlacedRect := ...

theorem candidate_is_valid :
  FinitePacking candidateContainer candidatePlaced := by
  native_decide
```

then the theorem is machine-checked.

### 6.4 Decidable checker

Make `FinitePacking` decidable for rational rectangles:

```lean
instance : Decidable (Rect.interiorDisjoint A B) := ...
instance : Decidable (Rect.contains A B) := ...
```

Then for finite lists:

```lean
def checkFinitePacking : Bool := ...
theorem checkFinitePacking_sound :
  checkFinitePacking container placed = true →
  FinitePacking container placed := ...
```

This is essential for large certificates.

## 7. Layer 2: telescoping tail area

Formalize:

\[
\sum_{n=N}^{M-1}\frac1{n(n+1)}=\frac1N-\frac1M.
\]

Lean theorem:

```lean
theorem finite_tail_telescopes
  (N M : ℕ) (hN : 0 < N) (hNM : N ≤ M) :
  (Finset.Icc N (M-1)).sum
    (fun n => (1 : ℚ) / ((n : ℚ) * ((n+1 : ℕ) : ℚ)))
  =
  (1 : ℚ) / N - (1 : ℚ) / M := ...
```

There may be off-by-one issues with `Finset.range`; choose a clean index convention.

Also formalize real version:

\[
\sum_{n=N}^{\infty}\frac1{n(n+1)}=\frac1N.
\]

This may require Mathlib infinite sums. If too hard initially, formalize finite telescoping and state infinite tail as a theorem later.

## 8. Layer 2: cellification lemma

Formalize the strip cellification lemma.

Statement over rationals or reals:

Let \(M,m>0\), \(M\ge m\), and \(N=\lceil M/m\rceil\). Partition the strip into \(N\) cells of size \(m\times M/N\). Then:

\[
\frac m2 < \frac MN \le m,
\]

so each cell has aspect ratio at most \(2\), and total semiperimeter is at most \(3M\).

Lean theorem skeleton:

```lean
theorem cell_width_bounds
  {M m : ℚ} (hm : 0 < m) (hM : m ≤ M) :
  let N : ℕ := Nat.ceil (M / m) -- may need real version
  ...
```

Practical advice:

- Ceil over rationals can be annoying.
- It may be easier to define a cellification certificate using an explicit natural `N` satisfying:
  \[
  M/m \le N < M/m+1.
  \]
- Then prove the bounds from this assumption.

Recommended theorem:

```lean
theorem cellification_bounds
  {M m : ℚ} {N : ℕ}
  (hm : 0 < m) (hM : m ≤ M)
  (hN1 : M ≤ (N : ℚ) * m)
  (hN2 : (N : ℚ) * m < M + m) :
  m / 2 < M / (N : ℚ) ∧
  M / (N : ℚ) ≤ m ∧
  (N : ℚ) * (m + M / (N : ℚ)) ≤ 3 * M := ...
```

This avoids formalizing `ceil`.

## 9. Layer 2: balanced LRP aspect control

Formalize:

Let \(X\ge Y>0\), \(XY\ge c/t\), \(X/Y\le R\), and cut \(s\le\alpha/t\) from the longer side. If

\[
t\ge \frac{\alpha^2R}{c(1-1/R)^2},
\]

then the new aspect ratio remains at most \(R\).

Recommended real theorem:

```lean
theorem balanced_lrp_aspect_control
  {X Y c t R α s : ℝ}
  (hY : 0 < Y)
  (hXY : Y ≤ X)
  (hArea : c / t ≤ X * Y)
  (hc : 0 < c)
  (ht : 0 < t)
  (hR : 1 < R)
  (hAspect : X ≤ R * Y)
  (hs : 0 ≤ s)
  (hsBound : s ≤ α / t)
  (hT : α^2 * R / (c * (1 - 1/R)^2) ≤ t)
  :
  let X' := X - s
  0 < X' ∧
  ((X' ≤ Y ∧ Y ≤ R * X') ∨ (Y ≤ X' ∧ X' ≤ R * Y)) := ...
```

A cleaner version can define aspect ratio as a predicate:

```lean
def AspectAtMost (R X Y : ℝ) : Prop :=
  0 < X ∧ 0 < Y ∧ X ≤ R * Y ∧ Y ≤ R * X
```

Then:

```lean
theorem balanced_lrp_aspect_control :
  AspectAtMost R X Y →
  ... →
  AspectAtMost R (X - s) Y := ...
```

## 10. Layer 2: endpoint potential lemma

Formalize:

If every endpoint has width at most \(C/t\), then:

\[
S_{\mathrm{ep}}\le \frac Ct P_{\mathrm{ep}}.
\]

For a finite list of rectangles:

```lean
theorem endpoint_area_bound_by_width_and_perimeter
  (eps : List Rect)
  {C t : ℝ}
  (ht : 0 < t)
  (hwidth : ∀ E ∈ eps, (E.width : ℝ) ≤ C / t)
  :
  (eps.map Rect.area).sum ≤ (C / t) * (eps.map Rect.semiperim).sum := ...
```

You may need real-valued versions of `Rect.width`, `Rect.height`, etc.

This theorem is straightforward:

\[
\operatorname{area}(E)=w(E)h(E)\le (C/t)h(E)\le (C/t)(w(E)+h(E)).
\]

## 11. Layer 2: normal-box sum bound

Formalize the analytic estimate:

If unused normal boxes have birth index \(k\ge c t^{1/\gamma}\) and area at most \(C k^{-\gamma-1}\), then:

\[
S_{\mathrm{norm}}(t)
\le
C' / t.
\]

This may be the hardest analytic Lean part because of real powers and sums.

Simplify by using a rational exponent such as:

\[
\gamma=\frac43.
\]

Then:

\[
k^{-\gamma-1}=k^{-7/3}.
\]

Lean’s real-power library can handle this, but it may be nontrivial.

Alternative: formalize a discrete bound as an assumption in the first Lean milestone, then later prove it.

A possible theorem:

```lean
theorem tail_sum_power_bound
  {γ K : ℝ}
  (hγ : 0 < γ)
  (hK : 0 < K) :
  (∑' k : ℕ, if K ≤ k then (k : ℝ)^(-(γ+1)) else 0)
  ≤ (1/γ) * K^(-γ) + error := ...
```

Practical staged plan:

- Stage A: prove finite integral comparison for rational exponents manually.
- Stage B: use Mathlib’s existing `Summable` / `HasSum` facts.
- Stage C: specialize to \(\gamma=4/3\) if general proof is too slow.

## 12. Layer 3: calibrated tail theorem

Formalize the tail theorem as a conditional theorem first.

Define an abstract scheduler state:

```lean
structure TailState where
  t : ℕ
  LRP : Rect
  normalBoxes : List NormalBox
  endpointBoxes : List Rect
  placedTail : List PlacedRect
```

Define invariants:

```lean
def GoodTailState (γ c R η : ℝ) (S : TailState) : Prop :=
  LRP_area_lower_bound S c ∧
  LRP_aspect_bound S R ∧
  endpoint_perimeter_bound S η ∧
  normal_width_law S γ ∧
  finite_packing_valid S
```

Then prove a conditional theorem:

```lean
theorem good_tail_state_never_stops
  {γ c R η : ℝ}
  (hγ1 : 1 < γ) (hγ2 : γ < 3/2)
  (hS : GoodTailState γ c R η S)
  :
  SchedulerCanContinue S := ...
```

Do not pretend this proves the whole open problem. It proves that the invariant system is sufficient.

### 14.2 Checker strategy

For large certificates, `native_decide` may be too slow if checking all pairs. Use a sweep-line certificate:

- Sort rectangles by x-coordinate.
- Provide a list of only potentially overlapping pairs.
- Prove the sweep-line certificate sound.

Initial milestone can use \(O(N^2)\) for \(N\le 1000\).
