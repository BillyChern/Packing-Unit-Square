## 1. Problem

We want to pack the infinite sequence of rectangles

\[
D_n=\frac1n\times\frac1{n+1},\qquad n=1,2,\dots
\]

inside the unit square \([0,1]^2\).

The total area is exactly

\[
\sum_{n=1}^{\infty}\frac1{n(n+1)}=1.
\]

This is Problem 2.37 from *Concrete Mathematics*.

The exact problem is open. Current best public results are approximate/computational or conditional.

\[
\boxed{

The key unresolved piece is the **Finite Burn-In / Warm-Start Lemma**:

> For every \(\varepsilon>0\), find some \(N\) such that \(D_1,\dots,D_{N-1}\) can be packed into \([0,1+\varepsilon]^2\) while leaving a “good calibrated tail state” for \(D_N,D_{N+1},\dots\).

A coding agent should focus on producing, checking, and improving finite warm-start states.

## 4. Key notation

For the tail beginning at index \(t\),

\[
S_{\mathrm{com}}(t)
=
\sum_{n=t}^{\infty}\frac1{n(n+1)}
=
\frac1t.
\]

We decompose remaining empty area into:

\[
S_{\mathrm{com}}(t)
=
S_{\mathrm{LRP}}(t)
+
S_{\mathrm{norm}}(t)
+
S_{\mathrm{ep}}(t),
\]

where:

- \(S_{\mathrm{LRP}}\): area of the largest rectangular piece or selected large rectangular piece.
- \(S_{\mathrm{norm}}\): area of normal boxes generated by calibrated Slack-Pack.
- \(S_{\mathrm{ep}}\): area of endpoint/absorber boxes.

The desired asymptotic invariant is:

\[
S_{\mathrm{LRP}}(t)
\ge
\frac{c}{t}
\]

for some fixed \(c>0\), with bounded LRP aspect ratio.

## 5. Proposed algorithmic framework

Fix

\[
1<\gamma<\frac32.
\]

Good initial choices:

```text
gamma = 4/3
gamma = 1.25
gamma = 1.4
```

Define calibrated active width:

\[
a_t=\frac1{t+1}+t^{-\gamma}.
\]

The calibrated scheduler should use:

1. **Endpoint priority**  
   If any endpoint/absorber can fit \(D_t\) or a calibrated active subbox, use it before cutting the LRP.

2. **Normal-box priority**  
   If no endpoint fits but a normal box fits, use a normal box.

3. **LRP cut**  
   Cut a new calibrated stripe from the LRP only if no endpoint or normal box fits.

4. **Calibration**  
   If a free box is wider than needed, cut a subbox of width exactly \(a_t\). The leftover strip should be cellified into fat absorbers.

5. **Two-backtrack anti-sliver**  
   When a row endpoint is too thin, undo one or two placements so that the endpoint thickness is \(\Theta(1/t)\).

6. **Balanced LRP cuts**  
   Always cut the next stripe from the longer side of the LRP.

## 6. Rigorous local lemmas already proposed

The code should be written to test and verify these numerically, and eventually certify them.

### 6.1 Two-backtrack anti-sliver

If a row ends near index \(t\) and the residual thickness \(\rho\) is too small, undo at most two rectangles. Then the final residual should satisfy:

\[
\frac{\lambda}{t}
\le
\rho^\star
\le
\frac{\lambda+C}{t}.
\]

Suggested constants:

```text
lambda = 1.1
C = 3.0
```

### 6.2 Endpoint-perimeter potential

Define

\[
P_{\mathrm{ep}}(t)=\sum_E (w(E)+h(E)).
\]

At an LRP-critical time, endpoint priority implies each live endpoint has width \(O(1/t)\), hence:

\[
S_{\mathrm{ep}}(t)\le \frac{C}{t}P_{\mathrm{ep}}(t).
\]

Therefore, keeping \(P_{\mathrm{ep}}\) small is enough.

### 6.3 Calibrated normal-box width

If a calibrated active box has width

\[
a_t=\frac1{t+1}+t^{-\gamma},
\]

then a normal box born at index \(j\) should have width approximately

\[
j^{-\gamma}.
\]

Test metric:

\[
r_j = \frac{w(B_j)}{j^{-\gamma}}.
\]

A good state should have \(r_j\) bounded between constants, e.g.

```text
0.25 <= r_j <= 4.0
```

Tighter is better.

### 6.4 Normal-box area estimate

At LRP-critical time \(t\),

\[
S_{\mathrm{norm}}(t)
\lesssim
\left(\frac1\gamma+\delta\right)\frac1t.
\]

Test this numerically.

### 6.5 LRP lower bound

At LRP-critical time \(t\), target:

\[
S_{\mathrm{LRP}}(t)
\ge
\left(1-\frac1\gamma-\delta\right)\frac1t.
\]

For \(\gamma=4/3\), the theoretical fraction is roughly \(1/4\).  
So practical target:

```text
LRP_area / tail_area >= 0.10 initially
LRP_area / tail_area >= 0.20 desirable
LRP_area / tail_area >= 0.25 excellent
```

### 6.6 Balanced LRP aspect control

If

\[
A_t\ge \frac{c}{t},\qquad \operatorname{aspect}(LRP_t)\le R,
\]

and stripe thickness satisfies

\[
s_t\le \frac{\alpha}{t},
\]

then cutting from the longer side preserves bounded aspect ratio for large \(t\).

In code, track:

```text
LRP_aspect = max(width, height) / min(width, height)
```

Target:

```text
LRP_aspect <= 10
```

Better:

```text
LRP_aspect <= 4
```

### 6.7 Cellification bookkeeping

When a long thin strip \(M\times m\), \(M\ge m\), is created, split it into

\[
N=\lceil M/m\rceil
\]

cells of dimensions

\[
m\times M/N.
\]

Then each cell has aspect ratio at most 2 and total semiperimeter at most \(3M\).

Implement this exactly.

## 10. Certificate checker

The checker must verify:

### 10.1 Containment

Every placed rectangle lies within the container.

### 10.2 Correct dimensions

For each \(D_n\), side lengths must equal either:

\[
\frac1n,\frac1{n+1}
\]

or rotated.

### 10.3 No overlap

For every pair of placed rectangles, interiors are disjoint.

For large \(N\), pairwise \(O(N^2)\) checking is too slow. Use sweep-line or spatial indexing, but keep an exact fallback for small certificates.

### 10.4 Free-state containment

All free boxes lie inside the container and avoid placed rectangles.

### 10.5 LRP condition

Verify:

\[
\operatorname{area}(LRP)\ge c/N.
\]

### 10.6 LRP aspect

Verify:

\[
\operatorname{aspect}(LRP)\le R.
\]

### 10.7 Endpoint semiperimeter

Verify:

\[
P_{\mathrm{ep}}=\sum_E(w(E)+h(E))\le \eta.
\]

### 10.8 Normal width law

For each normal box with birth index \(k\), verify:

\[
c_1 k^{-\gamma}\le w(B_k)\le c_2 k^{-\gamma}.
\]

Because this involves irrational powers if \(\gamma=4/3\), either:

- choose rational-computable \(\gamma\) and use interval arithmetic, or
- verify using high-precision interval arithmetic.
