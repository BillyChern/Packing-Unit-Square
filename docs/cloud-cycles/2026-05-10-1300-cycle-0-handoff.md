## The precise residual gap

The framework needs a **rate-limited interleaving scheduler**:
- Fires one absorber per O(t^{1/γ}) normal placements.
- Under this scheduler + N7 balanced cuts, the cumulative bound closes:
  `C_1 · Σ √(R/(c·t)) ≤ Δ · Σ 1/t + η`
  with LHS = O(T^{−1/γ}) → 0.
- This scheduler design is ABSENT from research notes §9.3.
